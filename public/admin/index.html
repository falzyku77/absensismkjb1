Rombel / naik kelas

Isi kolom "Pindah ke kelas" pada kelas yang ingin dipindahkan, kosongkan jika tidak berubah. Semua siswa di kelas itu ikut pindah. Kode dan barcode siswa tidak berubah, jadi kartu lama tetap bisa discan. Untuk memindahkan satu siswa saja, pakai tombol Edit di tab Siswa.

Kartu siswa

Scan QR dengan kamera HP (satu Wi-Fi dengan komputer). Hasil cetak: kertas A4, 10 kartu per lembar. Admin: klik kartu mana saja untuk mengubah warnanya langsung.

Edit warna kartu

Geser warna di bawah, kartu di halaman berubah langsung. Kartu yang sedang diedit ditandai garis putus-putus emas.

Warna tema cepat:

Scan kartu

Scanner USB bekerja seperti keyboard: klik kolom di atas lalu scan. Untuk kamera di HP, buka alamat HTTPS yang tampil di terminal.

Suara hasil scan

Atur suara untuk tiap hasil scan: pilih nada, suara bicara (bisa pakai nama siswa), atau unggah file suara sendiri. Pengaturan tersimpan di server, jadi berlaku di semua perangkat yang dipakai scan.

Jam absensi

Kehadiran hanya tercatat jika kartu discan pada rentang jam sesi berikut (mengikuti jam server di bagian atas). Admin dapat mengubah atau menambah sesi (misalnya Masuk Pagi, Masuk Siang, Pulang) kapan saja.
Untuk kelas: pilih Masuk pagi / Masuk siang agar sesi itu hanya untuk kelas yang masuk pagi / siang (kelasnya ditetapkan di Panel Guru → Sesi Masuk & Terlambat). Batas terlambat: siswa yang scan setelah jam ini otomatis berstatus Terlambat dan mendapat poin ringan. Jam di sini juga yang tampil di bar jam bagian atas dan dipakai rekap Excel.

Atur sesi aktif secara manual

Dipakai jika jam komputer server kurang tepat atau ada kegiatan khusus. Pilih "Otomatis" agar mengikuti jam.

Cadangan & pindah data

Semua data (nama, kelas, kode kartu/barcode, riwayat absensi, dan jam absensi) tersimpan di file data.json di folder aplikasi, dan salinan otomatis harian di folder backup. Untuk memakai data yang sama di komputer lain: unduh cadangan di sini, lalu pulihkan di aplikasi komputer tujuan. Kode siswa tidak berubah, jadi kartu yang sudah dicetak tetap bisa discan. File cadangan dari aplikasi absensi sholat juga bisa dipulihkan di sini (yang diambil hanya data siswa; kode/barcode tetap sama).

Akun siswa (otomatis dari data siswa)

Siswa masuk ke portal dengan username = kode kartu dan password awal = kode kartu (siswa bisa menggantinya di menu Profil Saya). Siswa lupa password: tab Siswa → tombol Reset PW. Setiap siswa di data (termasuk hasil import) otomatis punya akun, tidak perlu dibuat satu per satu.
