Rekap Absensi Excel Bulanan

Unduh Excel

Isi file: sheet Ringkasan Kelas, Rekap Pagi, dan Rekap Siang (tiap siswa per tanggal: H/T/S/I/A + total + % hadir). Kelas masuk pagi/siang diatur di menu Sesi Masuk & Terlambat.

Rekap Otomatis Tersimpan

Server membuat file rekap sendiri untuk setiap bulan yang sudah lewat (pagi & siang sekaligus). File tersimpan juga di folder rekap/ pada komputer server.
